Billing

To take payments, paste your payment-link URL into the PAYMENT_LINK environment variable on the server and restart it. Works with any provider that gives a plain checkout link (e.g. Stripe Payment Link, Paystack). No secret keys are stored in this app. Note: Paddle Billing has no standalone checkout link — it needs a Paddle.js integration instead.
